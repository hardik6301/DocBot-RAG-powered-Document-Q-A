# DocBot

RAG-powered Document Q&A — UI built from the Stitch design system (light corporate minimalism).

## Stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS (Stitch tokens)
- Framer Motion (subtle page motion)
- Inter + JetBrains Mono

## Develop

```bash
npm install
npm run dev
```

- Landing: http://localhost:3000  
- Dashboard: http://localhost:3000/dashboard  
- Chat preview: http://localhost:3000/chat/q3-market
